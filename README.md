# Clive Fernandes — Interactive Portfolio

A personal portfolio built with React, Vite, Three.js and React Three Fiber.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Before publishing

Replace:
- `YOUR-EMAIL@example.com`
- LinkedIn URL
- GitHub URL
- Project descriptions/details as needed
- Add your resume PDF to `public/resume.pdf` and add a Resume button if desired.

## Build

```bash
npm run build
```

## GitHub Pages

For GitHub Pages, the easiest route is to use GitHub Actions with a Vite deployment workflow, or deploy the generated `dist` folder through your preferred Pages setup.
